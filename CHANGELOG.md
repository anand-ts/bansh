# Changelog

## Unreleased

## 0.1.5 — 2026-10-21

- Respect caret moves and selections inside a composition, including separator insertion and commits at the composition length limit.
- Preserve vowel harmony after cursor navigation through converted Cyrillic text.
- Open the mapping reference at its first section.

## 0.1.4 — 2026-07-28

- Turned the <kbd>Control</kbd> + <kbd>/</kbd> mapping reference into a native, scrollable macOS utility panel.
- Expanded the reference to all 62 user-facing mappings, including vowel harmony, forced vowels, and quote forms.
- Added regression coverage for both macOS shortcut event paths, toggling, Escape and deactivation dismissal, screen-bound positioning, and every displayed mapping.
- Replaced the application and README artwork with the approved classic bansh icon and retained editable vector sources.
- Added a matching monochrome, Retina-ready template icon for the macOS input-source menu and menu bar.

## 0.1.3 — 2026-07-26

- Replaced the 16×16 application icon with an original multi-resolution macOS icon.
- Added a daily GitHub release check with **Download Update** and **Remind Me Later** actions.
- Updated the installer and uninstaller to clean up older per-user Bansh copies.
- Kept the existing small monochrome icon specifically for the macOS input-source menu.
